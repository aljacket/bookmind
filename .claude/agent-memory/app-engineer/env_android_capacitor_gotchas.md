Checked 2026-10-08 on the operator's Mac while doing card #50 (Capacitor 8 / API 36).

-   **JDK**: Android Studio 2026.2's JBR is JDK 25 (not 21). Use Temurin 21: `/Users/alfonsocavalieri/.sdkman/candidates/java/21.0.12-tem` via inline `JAVA_HOME` + `PATH`. Gradle 8.2.1 (Capacitor 6) needs JDK 17 (the PATH default). `ANDROID_HOME=/Users/alfonsocavalieri/Library/Android/sdk` must be set (no `local.properties`).
-   **`npx cap migrate`**: needs `--noprompt --packagemanager npm` (stdin prompts break). It runs a platform-less `cap sync` that aborts on CocoaPods when `ios/` exists, before the Android steps: move `ios/` out of the tree during the run, then restore + `git diff --exit-code <base> -- ios`. It also re-resolves hundreds of lockfile packages and rewrites package.json to 2-space: restore both and use `npm install --package-lock-only` instead.
-   **Lint (card #57, 2026-10-08)**: `npm run lint` is verify-only; `npm run lint:fix` rewrites ~15 files (prettier): never run it on the repo inside a feature PR, test it in a scratch copy (rsync + symlinked node_modules). Native/openspec folders are excluded via `ignorePatterns` in .eslintrc.cjs; ~450 prettier/vue style warnings on main are expected until card #58. The airbnb-base / LoginPage.spec red seen during card #50 was fixed on main.
-   **Bash hook (worktree agent)**: a command like `npm run trello -- N --comment "PR ... https://..."` is refused (cannot prove it is not git), and so are commands using shell variables for adb/paths. Put such calls in a script under the scratchpad and run `bash /abs/script.sh`. zsh has no `PIPESTATUS`: use `&&` chains to check exit codes.
-   **Hook quirks (worktree-isolated Bash)**: any command containing `git` must be a single simple command (no `&&`, no heredoc with `<`/`{}`; use `git commit -F file`), no `export VAR=$HOME...`, no commands with computed paths in variables. Put multi-step logic in scripts written to the scratchpad and run them. The Write/Edit tools run prettier on repo files (reformats the whole file): use python/sed via Bash for byte-exact edits.
-   **macOS has no `timeout`**; Bash tool blocks `sleep N` chains: poll with a bounded `for` loop. Run Gradle/emulator/long scripts with `run_in_background`.
-   **Emulators**: two AVDs at once plus Gradle starve the host (system_server ANRs). Run one emulator at a time; `./gradlew --stop` before booting. `adb -s emulator-5554 emu kill` to stop. Disable Gboard stylus dialog: `settings put secure stylus_handwriting_enabled 0`. The Pixel_9_API_35 AVD already holds a real Firebase session. AVD WebView is 133 (< 140): System Bars plugin pads natively and `--safe-area-inset-*` are 0.
-   **Driving the WebView without credentials**: `adb forward tcp:9222 localabstract:webview_devtools_remote_<app pid>`, then Chrome DevTools Protocol over WebSocket (node 22 has global WebSocket). Fake user: `#app.__vue_app__.config.globalProperties.$pinia.state.value.auth.user = {uid,...}` then `$router.push`. Reading list is IndexedDB `BookMindDB` keyed by uid.
-   **Dev backend from the emulator**: `network_security_config.xml` forbids cleartext; `http://10.0.2.2:8000` needs a local-only overlay (cleartextTrafficPermitted on the 10.0.2.2 domain-config + capacitor `android.allowMixedContent`). Never commit it. Backend: `bookmind-server/venv/bin/uvicorn main:app` (main checkout venv) with `bookmind-server/.env` symlinked.
-   Chrome DevTools MCP cannot save screenshots to the scratchpad (workspace-root restriction): save them inside the worktree (untracked `.qa-shots/`, never commit).
-   **Verifying without credentials/backend (card #59)**: a ~60-line node stub of the backend (same transcript limits as `bookmind-server/main.py`, a `/__mode?recs=fail` toggle, a request log) plus `VITE_API_BASE_URL=http://localhost:8765 npx vite --port 5199`; fake the user as above. Dev builds expose `textarea.__vueParentComponent.setupState` (userTurnCount etc.); production APKs do not.
-   **APK against the stub**: temporary overlay (never commit) = `cleartextTrafficPermitted="true"` on the 10.0.2.2 domain-config + `android: { allowMixedContent: true }` in capacitor.config.ts; `VITE_API_BASE_URL=http://10.0.2.2:8765 npx vite build && npx cap sync android && ./gradlew assembleDebug`; then `git checkout` both files. Gradle works with Temurin 21 (`~/.sdkman/candidates/java/21.0.12-tem`).
-   **mobile-mcp**: the emulator id is `Pixel_9_API_36` (not `emulator-5554`). `mobile_type_keys` with `submit:true` loses characters if the textarea is disabled while awaiting: wait between turns. Android BACK with the keyboard open only hides the keyboard; a second BACK leaves the app from Preferences.
-   **Testing the app against a local HTTP backend on the emulator (card #62, 2026-10-09)**: the Capacitor 8 WebView (origin `https://localhost`) blocks `http://10.0.2.2:8000` as mixed content, and `android.allowMixedContent` is not applied by the Capacitor 8 bridge. WebView flag files do nothing on `user` emulator builds. What works (all temporary; run `git checkout capacitor.config.ts android` afterwards): `plugins.CapacitorHttp.enabled: true` (native HTTP, so no Origin header) plus `cleartextTrafficPermitted="true"` on the `10.0.2.2` domain-config in `android/app/src/main/res/xml/network_security_config.xml` (that file already trusts user CAs for 10.0.2.2). A real server-side `Origin` capture needs HTTPS to 10.0.2.2 with a CA the app trusts. The WebView page origin is `https://localhost` (the logcat Mixed Content warning shows it). The Pixel_9_API_36 AVD also holds a real Firebase session (operator test account), so the chat is reachable without logging in.
-   **Driving the chat by adb**: `input text` is flaky with Gboard autocomplete (use short words); `input keyevent 111` (ESC) hides the keyboard, `66` (Enter) submits the textarea. Capacitor logs the Bearer token in logcat at verbose level: never print it.
